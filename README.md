## 📌 Project Overview
**TaskMatrix** is an enterprise-grade Agile project management platform inspired by industry standards like Jira and Trello. It provides modular workspace management, sprint planning, backlog tracking, and interactive Kanban boards for high-efficiency software development teams.

## 🚀 Getting Started & Installation

### 1. Clone the Repository
\`\`\`bash
git clone https://github.com/your-username/prodesk-capstone-TaskMatrix.git
cd prodesk-capstone-TaskMatrix
\`\`\`

### 2. Run Backend Server
\`\`\`bash
cd server
npm install
npm run dev
\`\`\`
*(Server runs successfully on port 5000)*[span_8](start_span)[span_8](end_span)

### 3. Run Frontend Client
\`\`\`bash
cd client
npm install
npm run dev
\`\`\`
*(Vite development server runs on port 5173)*[span_9](start_span)[span_9](end_span)
